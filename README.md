# Тестовое задание 

Все изменения слиты в dev, также в репозитории есть билд. Дополнительно можно было бы реализовать отправку медиа, создание новых чатов (зарегиститрировано 9 пользователей, но чаты только с тремя. Создать новые можно отредактировав useChatStorage), реализовать индикацию просмотренных сообщений при помощи наблюдателей. Ниже распишу некоторые решения и фичи, чтобы в проекте было проще ориентироваться.

## Реализация

- Все данные работают через Pinia. Все манипуляции с чатами и пользователями происходят через методы хранилищ.

- Все фичи работают "по-настоящему", то есть все изменения - это не просто визуальное отображение - меняются данные объектов, на основании которых происходит отрисовка.

- Все приложение типизировано

- Для всех сущностей реализованы интерфейсы и модели

- Работают поиски по чатам и сообщениям, также нажав на три точки в шапке чата можно дать пользователю верификацию

- Сообщения отправляются только с содержанием, эмоджи работают. Отправить сообщение можно как нажатием на кнопку, так и клавишей Enter

- При сворачивании чатов непрочитанные сообщения отображаются на аватарках

- Непрочитанные сообщения можно добавить через хранилище, тк все сообщения, написанные в самом чате автоматически считаются прочитанными

- Последний визит тоже основывается на опциональном поле User lastSeen. Если оно не передано в конструктор, то будет установлена текущая дата.
